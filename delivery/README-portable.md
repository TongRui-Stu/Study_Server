# 在线学习平台便携运行版

适用于64位Windows 10/11。完整解压到可写文件夹后，双击`启动.bat`，不要在压缩包内部直接运行。无需安装IDEA、Node.js、Maven或JDK，包内含Java 17和MySQL 8运行时。

## 使用

1. 在窗口中选填DeepSeek和千问密钥，也可全部留空，然后点击“启动平台”。
2. 首次启动会创建独立数据库并导入完整题库，可能需要几十秒。等待窗口显示“启动成功”并打开浏览器。
3. 管理员：`admin / Admin@123`；学生：`student / Student@123`。也支持自行注册。
4. 保持启动器窗口打开。点击“停止服务”或关闭启动器会停止本包的后端和数据库；仅关闭浏览器不会停止服务。
5. 下次启动会保留题目修改、注册用户和学习记录，AI密钥需重新填写。停止后再启动时输入框也保持为空。

密钥仅进入本次后端子进程，不写入配置、系统环境变量、日志或数据库。不填写密钥时，练习、判题、收藏、错题、统计和Excel导入导出正常使用；AI入口会提示未配置。AI需要网络和有效额度。

## 数据与文件

题库完整保留703道题、2236个选项，以及4个科目、15个章节、70个知识点。题目内容、答案、解析、难度和状态未删改；创建人改为演示管理员。原作者的个人账号和学习记录不随包提供。

- `data/`：首次启动后生成的独立数据库、本地随机数据库凭据和JWT配置。不能在运行时移动或复制。
- `logs/`：MySQL与后端运行日志，故障时可查看。
- `runtime/`：包内Java和MySQL，仅用于这一份平台。
- `web/`、`app/`：已构建页面及后端程序。
- `sql/`：首次初始化用的题库SQL，后续启动不会重复导入。

数据库与网页均仅监听127.0.0.1，启动时自动选用空闲端口。不安装系统服务、不更改系统PATH、不使用或关闭电脑原有MySQL。若同时复制多套平台，每套使用各自数据目录。

为兼容中文和空格目录，启动时会分配一个空闲的临时盘符，指向本包目录；正常退出后自动移除，不占用已有盘符。

## 故障与备份

- 缺文件：重新完整解压。
- 提示已启动：使用已有启动器窗口，避免重复启动同一目录。
- 首次数据库初始化中断：先关闭启动器，确认无本包进程；将本包的`data`目录重命名备份，再重新启动。此操作会创建新的演示库，不会恢复原有学习记录。
- 正常备份：先停止服务，再复制整个便携版目录（包括data）。恢复也应在停止状态下操作。
- 页面打不开：查看窗口状态和`logs/server.log`；使用窗口中的“打开浏览器”按钮。

公开分享请使用最初收到的干净压缩包，避免把运行后产生的账号、学习记录、本地凭据一起发送。第三方运行时的来源及许可见`THIRD-PARTY.md`和runtime内的许可文件。
